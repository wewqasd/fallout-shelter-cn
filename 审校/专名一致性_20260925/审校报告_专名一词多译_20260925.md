## 一、中英对照表 vs 编译产物（结论：发布件严格一致）

### 1.1 编译读取的是哪张表

| 文件 | 角色 | 是否参与编译 |
|---|---|---|
| `data/translations.json` | **权威翻译表** | ✅ `patcher.py` / `resources.py` 唯一读取源 |
| `data/i2_dump.json` | EN 基准（版本情报、前置校验参考） | ✅ 打包进 EXE，做校验用 |
| `data/en_zh_pairs.tsv` | **派生产物**（`scripts/make_pairs.py` 由上面两个文件生成） | ❌ 仅供人看，改它不影响编译 |
| `data/translations.tsv` | 人类可读视图（续行块格式：空行=换行） | ❌ 无任何代码读取 |

编译流程（`src/fs_cn/patcher.py:319-378`）：定位包内 I2 LanguageSource → 逐个 term 用 **key 反查** `translations` → 写回。
同时有前置校验 `validate_translation()`：占位符数量、换行数、BBcode 标记与**包内 EN** 比对，不一致直接报错中止。

### 1.2 三表一致性（本次实测，全部 0 差异）

```
translations.json         14064 键
translations.tsv          14064 键   与 json 差异 0
en_zh_pairs.tsv(中文列)    14064 键   与 json 差异 0
en_zh_pairs.tsv(EN列)      14064 键   与 i2_dump.json[0] 差异 0
```

### 1.3 出厂产物内嵌译文

| 产物 | 内嵌 translations.json | 与当前表差异 |
|---|---|---|
| **Release v1.0 的 `FalloutShelterCN.exe`**（2026-09-16 07:28 重传，33896215 B） | md5 `3db9eb77b489…` | **0 条（完全一致）** |
| 本地 `build/exe/FalloutShelterCN.exe`（2026-09-10 06:31，33872231 B） | md5 `090a6aa76221…` | **1569 条不同**（旧 09-10 版译文） |

Release 内嵌表校验方式：自写 CArchive 解析器从 EXE 中抽出 `data/translations.json`（1426393 B，zlib）后逐条比对。
说明：本地 `build/` 是 09-10 的遗留构建（之后又有 12 个提交、1569 条修订），**不代表发布状态**。
Release 的另一个资产 `data.unity3d`（530 MB）与 EXE **同一时间戳重传**，未逐字节验证（需下载 530 MB）。

### 1.4 结论

1. 线上发布件（EXE）**严格按当前对照表/翻译表编译**，逐条 0 差异；
2. 对照表 `en_zh_pairs.tsv` 不是编译输入，而是输出。**若要改译文，必须改 `translations.json` 再重跑 `make_pairs.py`**，否则会"改了不生效"；
3. 本地 `build/exe/FalloutShelterCN.exe` 已过期 1569 条，建议删除或重新打包，避免误分发。

## 三、落地建议

1. **改哪里**：只改 `data/translations.json`（或 `translations.tsv` 后同步回 json），**不要**直接改 `en_zh_pairs.tsv`。
2. **改完必须重生对照表**：`python3 scripts/make_pairs.py`，否则对照表与权威表脱钩。
3. **重打包**：Release 的 EXE 当前与表一致；本次修订后需重新 `pyinstaller tools/build_exe.spec` 并重传资产（否则又会出现"发布件落后 1569 条"那种情况）。本次修订共 **82 条 key**（56 条可直接机械替换、21 条为物品名决策项、5 条需人工改写），逐条列在 `fix_list.tsv`。
4. **验证**：
   ```
   python3 审校/专名一致性_20260925/check_tables.py          # 三表一致性（应全 0）
   python3 审校/专名一致性_20260925/count_variants.py        # 异译写法计数（异译应归零）
   python3 审校/专名一致性_20260925/extract_exe_data.py <新EXE> <目录>  # 校验新 EXE 内嵌表 == 当前表
   ```
5. **优先级**：先修 #1 Outfit(25)、#2 Vault-Tec(7)、#3 Pet Carrier(10)、#4 Living Quarters(5)，四项占总异译量的 70%。
