# 专有名词提取与官方译名对照（2026-10-01）

## 一、提取方法

全部为**确定性提取**，不依赖模型猜测：

1. **句内大写序列挖掘**：对 14064 条英文原文（`data/i2_dump.json` 索引 0）做大写词序列匹配，
   剔除句首词与常见词，得到 1962 个候选 → 按「非句首出现次数」筛后 769 个。
2. **名字类 key 直取**：`Weapon_Name_*` / `Outfit_Name_*` / `Pet_*` / `Junk_*` /
   `Theme_Name_*` / `Room_*` / `QuestLoc_*_QuestName|QuestlineName` / `Achievement_*`，
   共 **1200 条**纯名称对（EN→ZH），这部分本身就是最干净的专名清单。
3. **合并去重**：两路合并后 1577 个候选。
4. **机械一致性检测**：
   - 同 EN 全文 → 多种中译：**16 组**（涉及 42 个 key）
   - 同中译 → 多种 EN：233 组（多为 TAP/CLICK、单复数、全大写孪生键，非缺陷）

## 七、curl + MediaWiki API 突破（2026-09-30）

`web_fetch` 被 DNS 拦（所有域名解析到 198.18.x.x 代理网段）**不代表网络不通**。
`curl` 实测：GitHub / 百度 200；Fandom、灰机 wiki 的**网页**返回 403，是 **Cloudflare「Just a moment…」人机校验**，与网络无关。

突破口：**MediaWiki API 不受 Cloudflare 挑战影响**

```
https://fallout.fandom.com/api.php?action=query&titles=<EN页面名>&redirects=1&prop=langlinks&lllang=zh&format=json
```

这个 `langlinks` 接口直接把**英文页面名映射成中文维基标题**，等于拿到了官方/社区译名表。
批量跑完 1758 个术语（36 批 × 50 条，0 失败），其中 **139 个有中文维基页面**，
去掉无中文名的、去重后 **126 条可比对** → 写出 [F_维基对照.tsv](F_维基对照.tsv)。

> 繁简转换用 `zhconv`（本次 `pip install --break-system-packages zhconv`），
> 早前用自建 926 字映射表做对比会产生大量假阳性。

  --data-urlencode "format=json"
